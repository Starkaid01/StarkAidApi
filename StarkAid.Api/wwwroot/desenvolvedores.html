Documentação da API StarkAid

Bem-vindo à documentação da API StarkAid! Esta documentação fornece informações detalhadas sobre todos os endpoints disponíveis para desenvolvedores integrarem seus aplicativos com a plataforma StarkAid.

⚠️ Autenticação: A maioria dos endpoints requer autenticação via JWT Bearer Token. Inclua o token no header Authorization: Bearer {token} em suas requisições.
🔒 Segurança: Todos os endpoints de dispositivos validam automaticamente a propriedade do recurso. Cada usuário só pode acessar seus próprios dispositivos. A validação de UserId é feita em todos os endpoints críticos.
⚡ Rate Limiting Híbrido: A API possui rate limiting em duas camadas:
  • Por Usuário (Primário):
    • Endpoints gerais: 100 requisições/minuto por usuário autenticado
    • IA (Super IA): 10 requisições/minuto por usuário
    • Controle IoT (Commands/publish): 5 requisições/minuto por usuário
  • Por IP (Secundário - Proteção DDoS):
    • Limite global: 200 requisições/minuto por IP
    • Config: 90 requisições/minuto por IP

Nota: O rate limiting por usuário é aplicado primeiro. O rate limiting por IP atua como proteção adicional contra ataques DDoS/Brute Force.

Base URL

https://starkaid.runasp.net/api/v1

🔐 Autenticação (Auth)

POST /api/v1/Auth/login

Autentica um usuário e retorna um token JWT e refresh token.

Público: Este endpoint não requer autenticação.

Request Body:

Campo Tipo Obrigatório Descrição
email string Sim Email do usuário
password string Sim Senha do usuário
origem string Não Origem da requisição (ex: "app", "web") 
{
  "email": "usuario@example.com",
  "password": "senha123",
  "origem": "app"
}

Response (200 OK):

{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refreshToken": "refresh_token_here",
  "user": {
    "id": "guid",
    "name": "Nome do Usuário",
    "email": "usuario@example.com",
    "apiKey": "api_key_here",
    "starkCoins": 100.0
  }
}
POST /api/v1/Auth/refresh-token

Renova o token de acesso usando um refresh token válido.

Público: Este endpoint não requer autenticação.

Request Body:

Campo Tipo Obrigatório Descrição
refreshToken string Sim Refresh token válido 
{
  "refreshToken": "refresh_token_here"
}

Response (200 OK):

{
  "token": "new_jwt_token",
  "refreshToken": "new_refresh_token"
}

🤖 Inteligência Artificial (IA)

Processa uma mensagem usando a Super IA. Consome StarkCoins baseado no custo da requisição.

⚡ Rate Limiting: Este endpoint possui rate limiting de 10 requisições/minuto por usuário (além do limite geral de 100 req/min).

Request Body:

Campo Tipo Obrigatório Descrição
texto string Sim Texto da mensagem do usuário

estilo string Não Estilo da resposta

  "texto": "Qual a capital do Brasil?",

  "contextoIA": "",
  "estilo": ""
}

Response (200 OK):

{

POST /api/v1/Commands/publish

Envia um comando para controlar um dispositivo StarkSwitch (ligar/desligar). O comando é enviado via MQTT.

🔒 Segurança: Este endpoint valida automaticamente se o dispositivo pertence ao usuário autenticado. Se o deviceId não pertencer ao usuário, retorna 403 Forbid.

Request Body:

Campo Tipo Obrigatório Descrição
deviceId Guid Sim ID do dispositivo
command enum Não* Comando predefinido: ligar, desligar, reiniciar, resetar
customCommand string Não* Comando customizado (texto livre)

* É necessário informar command OU customCommand, mas não ambos. 

{
  "deviceId": "guid",
  "command": "ligar"
}
{
  "deviceId": "guid",
  "customCommand": "comando_customizado"
}

Response (200 OK):

{
  "message": "Comando 'ligar' enviado.",
  "topic": "starkaid/{userId}/{deviceId}/commands"
}
⚡ Rate Limiting: Este endpoint possui rate limiting de 5 requisições/minuto por usuário para prevenir spam de comandos IoT.
Nota: Requer que o serviço MQTT esteja conectado. Se não estiver, retorna 503.

🔐 Autenticação (Login)

Exemplo completo de login e obtenção do token:

public LoginResponse login(String email, String password) throws IOException {
    JsonObject requestBody = new JsonObject();
    requestBody.addProperty("email", email);
    requestBody.addProperty("password", password);
    requestBody.addProperty("origem", "app");
    
    RequestBody body = RequestBody.create(
        requestBody.toString(),
        MediaType.parse("application/json")
    );
    
    Request request = new Request.Builder()
        .url(BASE_URL + "/Auth/login")
        .post(body)
        .build();
    
    try (Response response = client.newCall(request).execute()) {
        if (!response.isSuccessful()) {
            throw new IOException("Erro no login: " + response);
        }
        
        String responseBody = response.body().string();
        LoginResponse loginResponse = gson.fromJson(responseBody, LoginResponse.class);
        
        // Salvar o token para próximas requisições
        this.token = loginResponse.getToken();
        
        return loginResponse;
    }
}

📡 Requisições Autenticadas

Método auxiliar para fazer requisições autenticadas:

private Request.Builder createAuthenticatedRequest(String endpoint) {
    if (token == null || token.isEmpty()) {
        throw new IllegalStateException("Token não configurado. Faça login primeiro.");
    }
    
    return new Request.Builder()
        .url(BASE_URL + endpoint)
        .addHeader("Authorization", "Bearer " + token)
        .addHeader("Content-Type", "application/json");
}

// Exemplo: Buscar informações do usuário
public User getUserInfo() throws IOException {
    Request request = createAuthenticatedRequest("/Users/" + getCurrentUserId())
        .get()
        .build();
    
    try (Response response = client.newCall(request).execute()) {
        if (response.code() == 401) {
            throw new IOException("Token expirado. Faça login novamente.");
        }
        
        if (!response.isSuccessful()) {
            throw new IOException("Erro: " + response);
        }
        
        String responseBody = response.body().string();
        return gson.fromJson(responseBody, User.class);
    }
}

🤖 Exemplo: Chamar Super IA

public String callSuperIA(String texto, String contextoUser, String contextoIA) throws IOException {
    JsonObject requestBody = new JsonObject();
    requestBody.addProperty("Texto", texto);
    requestBody.addProperty("ContextoUser", contextoUser != null ? contextoUser : "");
    requestBody.addProperty("ContextoIA", contextoIA != null ? contextoIA : "");
    requestBody.addProperty("Estilo", "");
    
    RequestBody body = RequestBody.create(
        requestBody.toString(),
        MediaType.parse("application/json")
    );
    
    Request request = createAuthenticatedRequest("/Users/ia/super")
        .post(body)
        .build();
    
    try (Response response = client.newCall(request).execute()) {
        if (response.code() == 429) {
            // Rate limit excedido
            String retryAfter = response.header("Retry-After");
            throw new IOException("Rate limit excedido. Tente novamente em " + retryAfter + " segundos.");
        }
        
        if (!response.isSuccessful()) {
            throw new IOException("Erro: " + response);
        }
        
        String responseBody = response.body().string();
        JsonObject jsonResponse = gson.fromJson(responseBody, JsonObject.class);
        return jsonResponse.get("message").getAsString();
    }
}

⚡ Tratamento de Rate Limiting

Exemplo de como tratar erros 429 (Too Many Requests) com retry automático:

public Response executeWithRetry(Request request, int maxRetries) throws IOException {
    Response response = null;
    int retryCount = 0;
    
    while (retryCount < maxRetries) {
        response = client.newCall(request).execute();
        
        if (response.code() != 429) {
            return response;
        }
        
        // Rate limit excedido - ler Retry-After
        String retryAfter = response.header("Retry-After");
        int delaySeconds = retryAfter != null ? Integer.parseInt(retryAfter) : (1 << retryCount);
        
        System.out.println("Rate limit excedido. Aguardando " + delaySeconds + " segundos...");
        
        try {
            Thread.sleep(delaySeconds * 1000L);
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            throw new IOException("Interrompido durante espera de rate limit", e);
        }
        
        response.close();
        retryCount++;
    }
    
    return response; // Retorna a última resposta (ainda 429)
}

// Uso:
public String callSuperIAWithRetry(String texto) throws IOException {
    JsonObject requestBody = new JsonObject();
    requestBody.addProperty("Texto", texto);
    requestBody.addProperty("ContextoUser", "");
    requestBody.addProperty("ContextoIA", "");
    requestBody.addProperty("Estilo", "");
    
    RequestBody body = RequestBody.create(
        requestBody.toString(),
        MediaType.parse("application/json")
    );
    
    Request request = createAuthenticatedRequest("/Users/ia/super")
        .post(body)
        .build();
    
    try (Response response = executeWithRetry(request, 3)) {
        if (!response.isSuccessful()) {
            throw new IOException("Erro após retries: " + response);
        }
        
        String responseBody = response.body().string();
        JsonObject jsonResponse = gson.fromJson(responseBody, JsonObject.class);
        return jsonResponse.get("message").getAsString();
    }
}

🔌 Exemplo: Controlar Dispositivo IoT

public boolean controlarDispositivo(String deviceId, String comando) throws IOException {
    JsonObject requestBody = new JsonObject();
    requestBody.addProperty("deviceId", deviceId);
    requestBody.addProperty("customCommand", comando);
    
    RequestBody body = RequestBody.create(
        requestBody.toString(),
        MediaType.parse("application/json")
    );
    
    Request request = createAuthenticatedRequest("/Commands/publish")
        .post(body)
        .build();
    
    try (Response response = client.newCall(request).execute()) {
        if (response.code() == 429) {
            String retryAfter = response.header("Retry-After");
            throw new IOException("Rate limit excedido para IoT. Limite: 5 req/min. Tente em " + retryAfter + " segundos.");
        }
        
        return response.isSuccessful();
    }
}

📝 Exemplo Completo de Uso

public class ExemploUso {
    public static void main(String[] args) {
        try {
            // 1. Criar cliente
            StarkaidApiClient client = new StarkaidApiClient();
            
            // 2. Fazer login
            LoginResponse login = client.login("seu@email.com", "suaSenha");
            System.out.println("Login realizado! Token: " + login.getToken());
            
            // 3. Buscar informações do usuário
            User user = client.getUserInfo();
            System.out.println("Usuário: " + user.getName());
            System.out.println("StarkCoins: " + user.getStarkCoins());
            
            // 4. Chamar Super IA
            String respostaIA = client.callSuperIAWithRetry("Olá, como você está?");
            System.out.println("Resposta IA: " + respostaIA);
            
            // 5. Buscar previsão do tempo
            WeatherForecast weather = client.getWeatherForecast("São Paulo");
            System.out.println("Temperatura: " + weather.getTemperatura() + "°C");
            
            // 6. Controlar dispositivo
            boolean sucesso = client.controlarDispositivo("device-id", "ligar");
            System.out.println("Dispositivo controlado: " + sucesso);
            
        } catch (IOException e) {
            System.err.println("Erro: " + e.getMessage());
            e.printStackTrace();
        }
    }
}

⚠️ Limites de Rate Limiting

  • Endpoints gerais: 100 req/min por usuário

  • Controle IoT: 5 req/min por usuário

Sempre implemente tratamento de erro 429 e respeite o header Retry-After.
