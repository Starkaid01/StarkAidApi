Introdução ao StarkAid Android

O StarkAid Android é um assistente virtual inteligente para dispositivos Android que permite controlar seu smartphone e dispositivos IoT através de comandos de voz. Com recursos avançados de automação, integração com dispositivos ESP, Ewelink e StarkSwitch, e inteligência artificial, o StarkAid transforma sua experiência de uso do celular.

Principais Funcionalidades

  • 🎤 Reconhecimento de Voz: Controle total através de comandos de voz
  • 🤖 Inteligência Artificial: Respostas inteligentes e contextualizadas
  • 🔌 Controle de Dispositivos: Gerencie dispositivos ESP, Ewelink e StarkSwitch
  • 📱 Controle de Apps: Abra aplicativos e controle funcionalidades do Android
  • 🎵 Integração Spotify: Controle música através de comandos de voz
  • 💬 WhatsApp: Envie mensagens via WhatsApp por voz
  • ⏰ Agendamentos: Automatize tarefas e comandos
  • 💰 StarkCoins: Sistema de créditos para uso de recursos premium

Instalação

Requisitos do Sistema

  • Android 6.0 (Marshmallow) ou superior
  • Microfone funcional
  • Permissões de microfone e localização (quando necessário)
  • Conexão com internet (para recursos de IA e sincronização)
  • Conta Google (para alguns recursos)

Processo de Instalação

  1. Baixe o arquivo APK do StarkAid Android
  2. Ative a instalação de fontes desconhecidas nas configurações do Android
  3. Execute o arquivo APK e siga as instruções de instalação
  4. Após a instalação, abra o aplicativo
  5. Na primeira execução, você precisará fazer login ou criar uma conta
  6. Conceda as permissões necessárias (microfone, localização, etc.)

Configuração Inicial

1. Login e Conta

Ao iniciar o aplicativo pela primeira vez, você precisará fazer login com suas credenciais. Se não tiver uma conta, você pode criar uma através da interface de login.

2. Configurar Assistente

Acesse as configurações do assistente para personalizar:

  • Nome do Assistente: O nome que você usará para ativar o assistente
  • Resposta Padrão: Mensagem que o assistente fala quando você chama apenas pelo nome
  • Personalidade: Escolha o estilo de resposta do assistente

Exemplo de Configuração:

Nome do Assistente

Jarvis
Quando você disser apenas "Jarvis", o assistente responderá com a resposta padrão configurada.

3. Configurar Integrações

O app permite configurar várias integrações:

  • Spotify: Conecte sua conta Spotify para controle de música
  • WhatsApp: Configure o WhatsApp para envio de mensagens
  • Ewelink: Faça login na plataforma Ewelink para controlar dispositivos
  • Inteligência Artificial: Ative/desative a IA conforme necessário

4. Permissões Necessárias

O aplicativo precisa das seguintes permissões:

  • Microfone: Para reconhecimento de voz
  • Localização: Para previsão do tempo e outras funcionalidades
  • Armazenamento: Para salvar dados e cache
  • Notificações: Para alertas e lembretes

Dispositivos

O StarkAid Android suporta três tipos de dispositivos IoT que podem ser controlados por voz:

1. Dispositivos ESP

Dispositivos ESP são controlados via UDP ou através da API. Você precisa configurar o dispositivo na API.

Configuração:

  1. Acesse a seção de dispositivos ESP no aplicativo
  2. Os dispositivos são sincronizados automaticamente da API
  3. Use comandos como "ligar [nome do dispositivo]" ou "desligar [nome do dispositivo]"

2. Dispositivos Ewelink

Dispositivos Ewelink são controlados através da API Ewelink. Requer login na plataforma Ewelink.

Configuração:

  1. Acesse a seção de dispositivos Ewelink no aplicativo
  2. Faça login na plataforma Ewelink
  3. Os dispositivos são sincronizados automaticamente após login
  4. Use comandos como "ligar [nome do dispositivo]" ou "desligar [nome do dispositivo]"

3. Dispositivos StarkSwitch

Dispositivos StarkSwitch são controlados via MQTT através da API StarkAid.

Configuração:

  1. Acesse a seção de dispositivos StarkSwitch no aplicativo
  2. Os dispositivos são sincronizados automaticamente
  3. Use comandos como "ligar [nome do dispositivo]" ou "desligar [nome do dispositivo]"

Comandos de Voz para Dispositivos

Você pode usar variações de comandos:

  • "Ligar [nome do dispositivo]"
  • "Desligar [nome do dispositivo]"
  • "Acender [nome do dispositivo]"
  • "Apagar [nome do dispositivo]"
  • "Liga [nome do dispositivo]"
  • "Desliga [nome do dispositivo]"
  • "Abrir [nome do dispositivo]" (para portas, cortinas, etc.)
  • "Fechar [nome do dispositivo]"

Agendamentos

Os agendamentos permitem automatizar ações em horários específicos. Você pode agendar:

  • Comandos para dispositivos
  • Ações recorrentes

Criar um Agendamento

  1. Acesse ⏰ Agendamentos no menu

  4. Salve o agendamento

Inteligência Artificial

O StarkAid Android possui um sistema de inteligência artificial integrado que pode responder a perguntas e executar tarefas complexas. A IA funciona em dois modos:

Modo Pergunta

Quando a IA está desativada, apenas perguntas são processadas pela IA. Comandos não reconhecidos que não sejam perguntas não serão processados.

Modo Completo

Quando a IA está ativada, todos os comandos não reconhecidos serão processados pela IA, não apenas perguntas.

Como Funciona

  1. Ative a IA através do switch no dashboard ou comando de voz
  2. Quando você fizer uma pergunta ou comando que não está configurado, a IA processará
  3. A resposta será falada pelo assistente
  4. Cada uso consome StarkCoins
  5. A IA se desativa automaticamente após 2 minutos de inatividade (modo completo)

Requisitos

  • Conexão com a internet
  • StarkCoins suficientes na conta
  • IA ativada no dashboard (para modo completo)

Exemplos de Uso

Perguntas Gerais

"Qual a capital do Brasil?"
"Me explique o que é inteligência artificial"
"Como fazer um bolo de chocolate?"

Tarefas Complexas (Modo Completo)

"Me dê dicas para melhorar minha produtividade"
"Qual a melhor forma de organizar arquivos no celular?"

StarkCoins

StarkCoins é o sistema de créditos do StarkAid usado para recursos premium, principalmente o uso da inteligência artificial e controle de música no Spotify.

Como Funciona

  • Cada uso da IA consome uma quantidade de StarkCoins
  • Tocar música no Spotify consome 0.2 StarkCoins por música
  • Você pode adicionar créditos através de planos
  • Alguns planos incluem StarkCoins mensais
  • StarkCoins não expiram

Adicionar StarkCoins

  1. Acesse 💰 StarkCoins | Planos no menu
  2. Escolha um plano ou adicione créditos diretamente
  3. Siga o processo de pagamento
  4. Os créditos serão adicionados automaticamente após confirmação

Verificar Saldo

O saldo de StarkCoins é exibido no dashboard principal. Você também pode verificar em 💰 StarkCoins | Planos.

Solução de Problemas

O assistente não está ouvindo

  • Verifique se o microfone está funcionando
  • Verifique as permissões de microfone nas configurações do Android
  • Reinicie o aplicativo
  • Verifique se o reconhecimento de voz está ativado no dashboard
  • Certifique-se de que o assistente não está "dormindo" (chame pelo nome do assistente primeiro)

Comandos não estão funcionando

  • Verifique se você está falando claramente
  • Confirme que o comando está configurado corretamente
  • Para comandos de dispositivos, verifique se o dispositivo está online
  • Verifique a conexão com a internet (para IA e sincronização)
  • Certifique-se de que o assistente está "escutando" (não dormindo)

IA não está respondendo

  • Verifique se a IA está ativada (switch no dashboard)
  • Confirme que você tem StarkCoins suficientes
  • Verifique a conexão com a internet
  • Verifique o status da API no dashboard
  • Lembre-se: se a IA estiver desativada, apenas perguntas serão processadas

Dispositivos não respondem

  • Para ESP: Verifique se o dispositivo está na mesma rede e online
  • Para Ewelink: Verifique se está logado na plataforma e se o dispositivo está online
  • Para StarkSwitch: Verifique se o dispositivo está online na API
  • Teste o dispositivo manualmente antes de usar comandos de voz
  • Verifique a conexão com a internet

Spotify não está funcionando

  • Verifique se o Spotify está instalado
  • Confirme que o switch do Spotify está ativado
  • Verifique se você tem StarkCoins suficientes (0.2 por música)
  • Certifique-se de que sua conta Spotify está conectada
  • Verifique a conexão com a internet

WhatsApp não está enviando mensagens

  • Verifique se o WhatsApp está instalado
  • Confirme que o switch do WhatsApp está ativado
  • Verifique se o contato está na lista de contatos sincronizados
  • Certifique-se de que o nome do contato está correto

Erro ao abrir aplicativo

  • Verifique se você tem a versão mais recente do aplicativo
  • Reinicie o dispositivo
  • Desinstale e reinstale o aplicativo
  • Verifique se todas as permissões foram concedidas
  • Verifique os logs de erro (se disponíveis)

Contato com Suporte

Se os problemas persistirem, você pode:

  • Usar o 💬 Chat Suporte no menu
  • Verificar os logs de erro do sistema
  • Reportar o problema através da interface de suporte
