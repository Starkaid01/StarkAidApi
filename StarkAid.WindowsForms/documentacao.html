Introdução ao StarkAid

O StarkAid é um assistente virtual inteligente para Windows que permite controlar seu computador e dispositivos através de comandos de voz. Com recursos avançados de automação, integração com dispositivos IoT, e inteligência artificial, o StarkAid transforma sua experiência de uso do computador.

Principais Funcionalidades

  • 🎤 Reconhecimento de Voz: Controle total através de comandos de voz
  • 🤖 Inteligência Artificial: Respostas inteligentes e contextualizadas
  • 🔌 Controle de Dispositivos: Gerencie dispositivos ESP, Ewelink e StarkSwitch
  • ⏰ Agendamentos: Automatize tarefas e comandos
  • 📚 Aprendizado: O sistema aprende com suas interações
  • ⏰ Alarmes e Lembretes: Nunca mais esqueça compromissos importantes
  • 💰 StarkCoins: Sistema de créditos para uso de recursos premium

Instalação

Requisitos do Sistema

  • Windows 10 ou superior
  • .NET 8.0 Runtime
  • WebView2 Runtime (instalado automaticamente se necessário)
  • Microfone funcional
  • Conexão com internet (para recursos de IA e sincronização)

Processo de Instalação

  1. Execute o instalador do StarkAid
  2. Siga as instruções do assistente de instalação
  3. Após a instalação, o aplicativo será iniciado automaticamente
  4. Na primeira execução, você precisará fazer login ou criar uma conta

Configuração Inicial

1. Login e Conta

Ao iniciar o aplicativo pela primeira vez, você precisará fazer login com suas credenciais. Se não tiver uma conta, você pode criar uma através da interface de login.

2. Configurar Assistente

Acesse 🤖 Configurar Assistente no menu lateral para personalizar:

  • Nome do Assistente: O nome que você usará para ativar o assistente
  • Resposta Padrão: Mensagem que o assistente fala quando você chama apenas pelo nome
  • Voz: Selecione a voz do assistente (disponível conforme sistema operacional)
  • Velocidade de Fala: Ajuste a velocidade da voz

Exemplo de Configuração:

Nome do Assistente

Jarvis
Quando você disser apenas "Jarvis", o assistente responderá com a resposta padrão configurada.

3. Configurar Conta

Em ⚙️ Configurar Conta, você pode:

  • Atualizar informações pessoais
  • Configurar endereço para agendamentos
  • Gerenciar preferências de notificação

Comandos Sociais Personalizável

Os comandos sociais são comandos personalizados que você pode criar para interações específicas. Eles permitem que você configure respostas personalizadas para comandos de voz.

Criar um Comando Social

  1. Acesse 💬 Comandos Sociais no menu lateral
  2. Clique em CRIAR
  3. Preencha os campos:
    • Comando: O texto que você dirá (ex: "me conte uma piada")
    • Resposta: O que o assistente responderá
    • Respostas Aleatórias (opcional): Múltiplas respostas que serão escolhidas aleatoriamente
  4. Clique em SALVAR

Exemplo de Configuração:

Comando

me conte uma piada

Resposta Padrão

Por que o programador não dorme? Porque ele tem bugs na cabeça!

Respostas Aleatórias (JSON)

{
  "alternativas": [
    "Por que o programador não dorme? Porque ele tem bugs na cabeça!",
    "O que é um terapeuta? 1024 gigaterapeutas!",
    "Por que os programadores preferem o modo escuro? Porque bugs são atraídos pela luz!"
  ]
}

Comandos Shell Personalizável

Os comandos shell permitem executar comandos do Windows (CMD/PowerShell) através de comandos de voz. Use com cuidado, pois comandos shell podem afetar o sistema.

Criar um Comando Shell

  1. Acesse 💻 Comandos Shell no menu lateral
  2. Clique em CRIAR
  3. Preencha os campos:
    • Comando de Entrada: O que você dirá (ex: "reiniciar computador")
    • Comando CMD: O comando que será executado (ex: "shutdown /r /t 0")
    • Resposta: O que o assistente dirá após executar
  4. Clique em SALVAR

Exemplos de Comandos Shell:

Reiniciar Computador

Comando de Entrada: reiniciar computador
Comando CMD: shutdown /r /t 0
Resposta: Reiniciando o computador agora

Abrir Arquivo

Comando de Entrada: abrir notepad
Comando CMD: notepad.exe
Resposta: Bloco de notas aberto

Comando com Delay

Comando de Entrada: abrir programa depois
Comando CMD: timeout /t 5 /nobreak >nul && start "" "C:\Programas\MeuApp.exe"
Resposta: Abrindo programa em 5 segundos
Este comando aguarda 5 segundos antes de abrir o programa.

⚠️ Avisos Importantes

  • Comandos shell executam com as permissões do usuário atual
  • Teste comandos em ambiente seguro antes de usar em produção
  • Comandos maliciosos podem danificar o sistema
  • Use apenas comandos que você entende completamente

Dispositivos

O StarkAid suporta três tipos de dispositivos IoT que podem ser controlados por voz:

1. Dispositivos ESP

Dispositivos ESP são controlados via UDP. Você precisa configurar o IP, porta e comandos.

Configuração:

  1. Acesse 📡 Dispositivos ESP no menu
  2. Clique em CRIAR
  3. Preencha:
    • Nome: Nome do dispositivo (ex: "Luz da Sala")
    • IP: Endereço IP do dispositivo
    • Porta: Porta UDP (geralmente 80 ou 8080)
    • Comando: Comando de voz (ex: "ligar luz da sala")
    • Comando para ESP: Comando que será enviado via UDP

2. Dispositivos Ewelink

Dispositivos Ewelink são controlados através da API Ewelink. Requer login na plataforma Ewelink.

Configuração:

  1. Acesse 🔌 Dispositivos Ewelink no menu
  2. Os dispositivos são sincronizados automaticamente após login
  3. Use comandos como "ligar [nome do dispositivo]" ou "desligar [nome do dispositivo]"

3. Dispositivos StarkSwitch

Dispositivos StarkSwitch são controlados via MQTT através da API StarkAid.

Configuração:

  1. Acesse 🔌 Dispositivos StarkSwitch no menu
  2. Os dispositivos são sincronizados automaticamente
  3. Use comandos como "ligar [nome do dispositivo]" ou "desligar [nome do dispositivo]"

Comandos de Voz para Dispositivos

Você pode usar variações de comandos:

  • "Ligar [nome do dispositivo]"
  • "Desligar [nome do dispositivo]"
  • "Acender [nome do dispositivo]"
  • "Apagar [nome do dispositivo]"
  • "Liga [nome do dispositivo]"
  • "Desliga [nome do dispositivo]"

Agendamentos

Os agendamentos permitem automatizar ações em horários específicos. Você pode agendar:

  • Comandos para dispositivos
  • Execução de arquivos
  • Ações recorrentes

Agendamentos de Dispositivos

  1. Acesse ⏰ Agendamentos no menu
  2. Clique em CRIAR
  3. Selecione o tipo de dispositivo (ESP, Ewelink ou StarkSwitch)
  4. Configure:
    • Dispositivo a ser controlado
    • Ação (ligar/desligar)
    • Data e hora
    • Recorrência (diário, semanal, etc.)

Agendamentos de Arquivos

  1. Acesse 📅 Agendamentos Arquivos no menu
  2. Clique em CRIAR
  3. Configure:
    • Caminho do arquivo a ser executado
    • Data e hora
    • Recorrência

Inteligência Artificial

O StarkAid possui um sistema de inteligência artificial integrado que pode responder a perguntas e executar tarefas complexas. A IA é ativada quando nenhum comando predefinido ou configurado corresponde ao que você disse.

Como Funciona

  1. Ative a IA através do botão no dashboard ou comando de voz
  2. Quando você fizer uma pergunta ou comando que não está configurado, a IA processará
  3. A resposta será falada pelo assistente
  4. Cada uso consome StarkCoins

Requisitos

  • Conexão com a internet
  • StarkCoins suficientes na conta
  • IA ativada no dashboard

Exemplos de Uso

Perguntas Gerais

"Qual a capital do Brasil?"
"Me explique o que é inteligência artificial"
"Como fazer um bolo de chocolate?"

Tarefas Complexas

"Me dê dicas para melhorar minha produtividade"
"Qual a melhor forma de organizar arquivos no computador?"

Sistema de Aprendizado

O sistema de aprendizado permite que o StarkAid aprenda novas respostas baseadas nas interações com a inteligência artificial. Quando ativado, o sistema salva automaticamente comandos e respostas da IA para uso futuro.

Ativar Aprendizado

  1. Acesse 📚 Configurar Aprendizado no menu
  2. Ative a opção "Aprendizado Habilitado"
  3. O sistema começará a salvar interações automaticamente

Como Funciona

  • Quando você faz uma pergunta à IA, o sistema salva o comando e a resposta
  • Na próxima vez que você disser algo similar, o sistema usará a resposta aprendida
  • Isso economiza StarkCoins, pois não precisa consultar a IA novamente
  • Você pode visualizar e gerenciar os aprendizados em 📚 Aprendizado

Gerenciar Aprendizados

Em 📚 Aprendizado, você pode:

  • Ver todos os comandos aprendidos
  • Editar respostas aprendidas
  • Deletar aprendizados indesejados

Alarmes e Lembretes

O sistema de alarmes permite criar lembretes através de comandos de voz ou interface gráfica.

Criar Lembrete por Voz

Você pode criar lembretes usando comandos como:

Exemplos de Comandos

"Me lembre de fazer compras hoje às 15 horas"
"Me lembre de ligar para João amanhã às 10 e 30"
"Crie um alerta para reunião no dia 25 de dezembro às 14 horas"

Gerenciar Alarmes

  2. Visualize todos os alarmes criados
  3. Crie, edite ou delete alarmes
  4. Veja alarmes disparados em ⏰ Alarmes

StarkCoins

StarkCoins é o sistema de créditos do StarkAid usado para recursos premium, principalmente o uso da inteligência artificial.

Como Funciona

  • Cada uso da IA consome uma quantidade de StarkCoins
  • Você pode adicionar créditos através de planos
  • Alguns planos incluem StarkCoins mensais
  • StarkCoins não expiram

Adicionar StarkCoins

  1. Acesse 💰 StarkCoins | Planos no menu
  2. Escolha um plano ou adicione créditos diretamente
  3. Siga o processo de pagamento
  4. Os créditos serão adicionados automaticamente após confirmação

Verificar Saldo

O saldo de StarkCoins é exibido no dashboard principal. Você também pode verificar em 💰 StarkCoins | Planos.

Solução de Problemas

O assistente não está ouvindo

  • Verifique se o microfone está conectado e funcionando
  • Verifique as permissões de microfone do Windows
  • Reinicie o aplicativo
  • Verifique se o botão de reconhecimento está ativado no dashboard

Comandos não estão funcionando

  • Verifique se você está falando claramente
  • Confirme que o comando está configurado corretamente
  • Para comandos de dispositivos, verifique se o dispositivo está online
  • Verifique a conexão com a internet (para IA e sincronização)

IA não está respondendo

  • Verifique se a IA está ativada (botão no dashboard)
  • Confirme que você tem StarkCoins suficientes
  • Verifique a conexão com a internet
  • Verifique o status da API no dashboard

Dispositivos não respondem

  • Para ESP: Verifique IP, porta e se o dispositivo está na mesma rede
  • Para Ewelink: Verifique se está logado na plataforma
  • Para StarkSwitch: Verifique se o dispositivo está online na API
  • Teste o dispositivo manualmente antes de usar comandos de voz

Erro ao abrir aplicativo

  • Verifique se o .NET 8.0 Runtime está instalado
  • Verifique se o WebView2 Runtime está instalado
  • Execute o aplicativo como administrador
  • Verifique os logs de erro (se disponíveis)

Contato com Suporte

Se os problemas persistirem, você pode:

  • Usar o 💬 Chat Suporte no menu
  • Verificar os logs de erro do sistema
  • Reportar o problema através da interface de suporte
